Power Apps formulas — Probationary Training Record, standalone rebuild
=======================================================================
Native Power Apps only. No Launch(), no web URL, no client ID,
no MSAL, no external site. The user signs in with their own
Microsoft account through the connectors.

Collections used in the app:
  colProfile  — one row: Name, Company, Shift, Captain, OfficerEmail
  colEntries  — one row per entry: Id, Date, Training, Comments
  varMonth    — text, "YYYY-MM", the month being viewed
  varShowAll  — true/false, month filter on/off

HERO SCREEN (HeroScreen — first screen in the app)
----------------------------------------------------
  Button "My training record"
    OnSelect:  Navigate(RecordScreen)
  Button "This month's report"
    OnSelect:  Navigate(ReportScreen)
  Button "Upload my saved record"
    OnSelect:  Navigate(UploadScreen)
  // No Launch() anywhere. Every button stays inside this app.

APP START (App.OnStart) — load the user's own record
------------------------------------------------------
  // OneDrive connector, signed in as the user.
  // Folder: "Probationary Training Record"
  // File:   "training-record.json"
  // If the file is not there yet, start blank — first save creates it.
  ClearCollect(
    colProfile,
    { Name: "", Company: "", Shift: "", Captain: "", OfficerEmail: "" }
  );
  ClearCollect(colEntries, []);
  // Load the file if it exists, parse its JSON into the collections.
  // (Use OneDrive.GetFileContent / a Power Automate flow to read the
  //  JSON text, then JSON() / ParseJSON() into colProfile/colEntries.
  //  Keep the file format exactly as in data-model.json.)

SAVE — RecordScreen, button "Save to my OneDrive"
----------------------------------------------------
  // Build the record JSON from the collections, same shape as
  // data-model.json, then write it to the same folder every time.
  Set(
    varRecordJson,
    JSON(
      {
        version: 1,
        profile: First(colProfile),
        entries: colEntries,
        updatedAt: Text(Now(), DateTimeFormat.UTC)
      },
      JSONFormat.IndentFour
    )
  );
  OneDrive.CreateFile(
    "Probationary Training Record",
    "training-record.json",
    varRecordJson
  );
  // If CreateFile refuses to overwrite, delete the old file first
  // with OneDrive.DeleteFile, then CreateFile again.
  // Show: "Saved to your OneDrive · " & Text(Now(), "h:mm AM/PM")

ADD ENTRY — RecordScreen, button "+ Add entry"
-----------------------------------------------
  Collect(
    colEntries,
    {
      Id: Text(Now(), "yyyymmddhhmmss") & Text(Rand(), "000"),
      Date: Today(),
      Training: "",
      Comments: ""
    }
  );

MONTH FILTER — RecordScreen gallery
------------------------------------
  // Gallery Items, month filtered unless Show all is on:
  If(
    varShowAll,
    Sort(colEntries, Date, SortOrder.Ascending),
    Sort(
      Filter(colEntries, Text(Date, "yyyy-mm") = varMonth),
      Date, SortOrder.Ascending
    )
  );

MONTHLY REPORT — ReportScreen
------------------------------
  // Table: this month's entries only, sorted by date:
  Sort(
    Filter(colEntries, Text(Date, "yyyy-mm") = varMonth),
    Date, SortOrder.Ascending

WHAT NOT TO DO
--------------
- No Launch(), no web link, no hosted page.
- No MSAL, no client ID, no redirect URL, no Azure registration.
- Do not save to a hidden app folder — Power Apps cannot reliably
  list hidden folders. Save to "Probationary Training Record",
  the visible folder, every time, same file name every time.
- Do not share one folder / one file between firefighters.
  The OneDrive connector runs as the signed-in firefighter,
  so each person only ever sees their own file.
